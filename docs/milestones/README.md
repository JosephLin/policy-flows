# Milestone screenshots

Each milestone gets a before/after pair taken the same way, so the two compare
cleanly:

- Light color scheme, so the scene is in daytime.
- The app pane at its normal width, with the map region (800 × 545) cropped.
- **overview**: the default camera after the page loads, with Esc pressed to
  stop the startup tour.
- **closeup**: 16 scroll steps in at the same point on the map.

"Before" is the live demo (`main`) and "after" is the branch. People, boats and
clouds move, so they will differ between shots.
